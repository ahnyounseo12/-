# RPG 턴제 전투 게임

1주차에 제작한 C++ 콘솔 턴제 RPG를 HTML, CSS, JavaScript로 다시 만든 웹 게임입니다. 별도 설치 없이 PC와 스마트폰 웹브라우저에서 플레이할 수 있습니다.

## 웹사이트

https://ahnyounseo12.github.io/-/

## 주요 기능

- 전사와 마법사 중 직업 선택
- 슬라임, 고블린, 드래곤으로 이어지는 3단계 전투
- 일반 공격, 특수 스킬, 방어, 포션 사용
- HP·MP·포션·턴·전투 기록 실시간 표시
- 단계 클리어 보상, 게임 클리어/게임 오버, 다시 시작
- PC와 스마트폰에 맞춘 반응형 화면

## 사용 방법

1. 위 웹사이트 주소에 접속합니다.
2. `모험 시작`을 누르고 직업을 선택합니다.
3. 화면의 행동 버튼을 누르거나 키보드 숫자키 `1`~`4`를 사용합니다.
   - `1`: 일반 공격
   - `2`: 특수 스킬
   - `3`: 방어
   - `4`: 포션

## 파일 구성

- `index.html`: 웹 화면 구조와 실행 진입점
- `styles.css`: 디자인 및 모바일 반응형 스타일
- `game.js`: 게임 규칙, 전투 처리, 화면 전환
